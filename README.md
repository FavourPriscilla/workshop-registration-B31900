PROJECT DESCRRIPTION
This is a website that i am working on. It enables computing students find suitable workshops where they can do specific projects in a conducive environment.
These workshops are all available on campus. The website enables students to make bookings for spots in these workshops.
An individual or group booking can be made depending on what the students prefer.
The website is still incomplete. It currently doesn't have a database. It is still in the building phase.
